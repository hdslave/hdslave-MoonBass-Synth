# Third-party material in MoonBass

MoonBass's own code and artwork are original to this repository. The borrowed pieces are:

- **CLAP headers** (`third_party/clap/include/`): the C Lever Audio Plug-in API by Alexandre Bique, MIT
  License. Licence text: [third_party/clap/LICENSE](third_party/clap/LICENSE).
- **Departure Mono** by Helena Zhang: the interface glyphs in `src/ui/font.h` are taken from this font,
  under the SIL Open Font License 1.1. Licence text: [licenses/OFL-departure-mono.txt](licenses/OFL-departure-mono.txt).
- **Melodee's plug-in screen header** (`src/melodee_screen.h`): copied from Melodee / hdslaveOS, MIT
  licensed so that any plug-in may copy it; the SPDX notice is at the top of the header itself.
